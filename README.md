# HC1 - Конструктор HTML сайта для Python
HC1 - это легковесная Python-библиотека для конструкций HTML-страниц.
Он позволяет создавать веб-страницы, используя чистый Python-код, без необходимости писать HTML вручную.

--- 

Способов написать сайт на библиотеке несколько, выделим из них объектно-ориентированное (когда просто используем классы) и использование контекстного менеджера `with`.

Идея программы заключалась в том что бы облегчить написание кода на HTML, потому что в текущее время им занимается ИИ, и этот язык хоть и очень легкий но читаемость оставляет желать лучшего...

## Теги и объекты

Пока что в первой версий тегов не так уж и много:

Имейте ввиду что все теги наследованы от Element поэтому они будут иметь `tag_name: str` хоть я их и не указал в **Основные параметры**.
Хорошая новость, то что `tag_name` будет автоматически заполнятся для каждого дочернего узла. Например `Heading` будет иметь имя тега `h{id}`. Где id - это уровень заголовка 
Пример: тег `h1` - очень большой заголовок.


|Тег    | Назначение    |Обязательные параметры| Html формат |
|-------|-------|-------|-------|
|`Element`|Это базовый тег, который создает все дочерние, с помощью ее вы можете создать новый тег (об этом позже) |`tag_name: str`| `<{tag_name}></{tag_name}>`|
|`Heading`|Текстовый заголовок |`text: str`, `level: int`| `<h{level}>{text}</h{level}>`|
|`Button`|Кнопка|`text: str`| `<button>{text}</button>` |
|`Input`|Поле ввода|| `<input>` |
|`Div`|Контейнер|| `<div></div>` |
|`Label`|Метка|`text: str`| `<label>{text}</label>` |
|`Paragraph`|Параграф|`text: str`| `<p>{text}</p>` |
|`Link`|Ссылка|| `<link>` |
|`Script`|Скрипт|| `<script></script>` |
|`Br`|Переход на новую строку|| `<br>` |

## Быстрый старт 

Создадим первый прототип сайта, который будет хранить тег заголовка и поле ввода для ввода имени.

Будем использовать объектно-ориентированный подход:

```py
from hc1 import (
    Html,                                    # Главный модуль
    Label,                                   # Метка
    Input,                                   # Поле ввода,
    Button                                   # Кнопка
)

site = Html("Мой сайт")     # Мой сайт - заголовок нашего сайта
# site.set_title("Мой сайт")
# Точно также меняет заголовок сайта

Label("Введите имя: ")
Input()
Button("Отправить")

site.save_html("index.html")
```

**Убедитесь что репозиторий находится на той же директорий где и ваш код**

Разберем код по полочкам:

1) **Импорт необходимых модулей и тегов**

```py
from hc1 import (
    Html,                                    # Главный модуль
    Label,                                   # Метка
    Input,                                   # Поле ввода,
    Button                                   # Кнопка
)
```

Html - это наш конструктор, даешь ему кирпичи (теги) он строит дом (сайт).

2) **Создание экземпляра сайта**

```py
site = Html("Мой сайт")
```
Мы создаем конструктор и задаем заголовок сайта `Мой сайт`. Этот параметр необязателен, вы можете изменить его потом.

3) **Размещение тегов**
```py
Label("Введите имя: ")
Input()
Button("Отправить")
```

4) **Сохранили в файл**
```py
site.save_html("index.html")
```


Видели магию? Мы просто создали объекты тегов, а они автоматически создались в самом сайте. Мы даже не указали в параметрах родителя (то есть объект `Html`). Но откуда то они добавились в тело `Html`. Каким образом?

В этом и плюс того что вы не указываете родителя явно - код становится короче. Но и огромный минус в том что вы не сможете без горящего зада создать несколько экземпляров сайта не усложнив код.

Дело в том что программа хранит единственный экземпляр текущего сайта, так называемая `Сессия текущего сайта`. Вы работаете с одним экземпляром Html-класса. 

Html-класс хранит статическую (привязанную к классу а не объекту класса) переменную `_current_site`. Она хранит последний созданный экземпляр сайта. Поэтому вы МОЖЕТЕ создать несколько экземпляров. Но переключаться между ними будет трудно, кроме того это нарушает один из принципов ООП - инкапсуляцию.

```py
site1 = Html("Первый сайт") # Текущая сессия сайта ссылается на это
# И пока сессия сайта ссылается на первый сайт
# все теги будут добавлены в тело первого сайта
Heading("Hi")

# Теперь _current_site (сессия текущего сайта) ссылается на site2
site2 = Html("Второй сайт")

# Сессия сменилась, поэтому параграф добавится на второй сайт
Paragraph("Это уже на втором сайте")

# Но я хочу добавить на первый сайт!
# Меняем сессию вручную
Html._current_site = site1

# Теперь сессия сайта снова ссылается на первый сайт
# и дальнейшие теги будут добавлятся на первый сайт
Heading("На первом сайте", level=3)
```

Поэтому для решения этой проблемы и облегчения написания кода и структурирования кода мы добавили логику контекстных менеджеров `with`.


## Контекстные менеджеры

Они нужны если вы хотите облегчить добавление нескольких сайтов и структуризовать контейнеры.


```py
from hc1 import (
    Html,                                    # Главный модуль
    Label,                                   # Метка
    Input,                                   # Поле ввода,
    Button                                   # Кнопка
)

# Создали контекстный менеджер с Html
# и все то что будет находиться внутри
# менеджера, будет добавляться именно в заданный в контексте Html
with Html("Мой сайт") as site:
    Label("Введите имя: ")
    Input()
    Button("Отправить")

site.save_html("index.html")
```

Код изменился но такой же рабочий. Давайте добавим несколько сайтов, и распределим их по файлам:

```py
from hc1 import (
    Html,                                    # Главный модуль
    Heading,                                 # Заголовок
)

with Html("Первый сайт") as site1:
    Heading("Первый сайт")
    site1.save_html("index1.html")

with Html("Второй сайт") as site2:
    Heading("Второй сайт")
    site2.save_html("index2.html")

with Html("Третий сайт") as site3:
    Heading("Третий сайт")
    site3.save_html("index3.html")

# Сайты можно сохранять и за пределами
# site1.save_html("index1.html")
# site2.save_html("index2.html")
# site3.save_html("index3.html")
```

Конструкция я бы даже сказал настолько легчайшая что не поймет ее только дебил (ахахха шутка!).
Каждый контекстный менеджер привязан к своему сайту. 

## Контейнер Div

Контейнер это тег который может хранить несколько тегов. Один из них это `Div`
Добавим один контейнер и добавим к нему 3 тега: `Heading`, `Label` и `Button`:

```py
from hc1 import (
    Html,
    Heading,
    Label,
    Button,
    Div,      # <- КОНТЕЙНЕР
)

site = Html("My site")
container = Div()
# С помощью метода append мы добавляем в контейнер тег
container.append(Heading("Заголовок контейнера"))
container.append(Label("Метка"))
container.append(Button("Кнопка"))

site.save_html("index.html")
```

#### Вот что получится в итоге:

index.html
```html
<!DOCTYPE html>
<html lang="ru">
  <html>
   <head>
    <meta charset="utf-8"/>
    <title>My site</title>
   </head>
   <body>
    <div>
     <h1>Заголовок контейнера</h1>
     <label>Метка</label>
     <button>Кнопка</button>
    </div>
   </body>
  </html>
</html>
```

Но легче всего, использовать Div внутри `with`:

```py
from hc1 import (
    Html,
    Heading,
    Label,
    Button,
    Div,      # <- КОНТЕЙНЕР
)

with Html("My site") as site:
    with Div():
        # Программа определяет что вы в контексте контейнера
        # и добавляет теги именно в контейнер
        Heading("Заголовок контейнера")
        Label("Метка")
        Button("Кнопка")

site.save_html("index.html")
```

## Параметризация тегов

Нам всегда нужно параметризировать теги, например добавить класс, айди, ссылку на что то. В hc1 это сделано очень легко. Если в html вы делали так:

```html
<link rel="stylesheet", href="style.css">
```

то в hc1 механика такая же:

```py
from hc1 import Html, Link
with Html("Тестирование ссылки") as site:
    Link(rel="stylesheet", href="style.css")
    # Программа сама создаст тег с такими параметрами
```


#### Что делать если тег совпадает с ключевым словом Python?

* Добавить _ в конце. Пример: `class_="container`
